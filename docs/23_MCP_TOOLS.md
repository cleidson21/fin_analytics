# MCP Tools (Pierre Finance)

## Visão Geral
A documentação extraída do llms.txt revelou cerca de 11 ferramentas (Tools) exportadas via MCP.
Essas ferramentas operam os endpoints REST subjacentes para acesso do LLM.

### Ferramentas Encontradas [VALIDADO]
1. getAccounts: Lista contas financeiras.
2. getApiKeyInfo: Verifica e descreve a API.
3. getTransactions: Lista transações e histórico.
4. getBills: Faturas de cartão de crédito.
5. getInstallments: Parcelamentos.
6. manageClosingDate: Datas de fechamento.
7. createSpendingLimit: Orçamentos.
8. paymentReminders: Lembretes de pagamento.
9. getExpensiveCategories: Análise avançada.
10. getMemories: Contexto financeiro do usuário.

## Conclusão
A oferta MCP espelha exatamente os furos do REST: **Não há ferramentas MCP para listar Investimentos, Posições ou Criptomoedas**.
