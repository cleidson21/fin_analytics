# Principles

- O domínio nunca conhece providers.
- Banco não é contrato.
- Frontend nunca conhece SQLite.
- Todo provider passa por Connector.
- IA nunca substitui regras.
- DTO nunca acessa banco.
- Repository nunca retorna dict.
- Toda integração produz Canonical Models.
- Main sempre executável.
- Develop é a branch oficial de desenvolvimento.
- Nenhuma API Key pode ser commitada.
