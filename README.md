## Sobre a V3 (Legacy)
O projeto Fin Analytics V3 era focado na ingestão de dados através de arquivos CSV e integração manual com regras de inteligência artificial aplicadas de maneira contínua sobre as importações. 

A partir deste momento, a arquitetura evoluiu para uma integração puramente baseada em Domínio (Domain-Driven), suportada por Open Finance (Pierre) e Agregadores de Patrimônio (MyProfit).
